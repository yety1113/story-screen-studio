# 小说影视改编

先读 [协作约定](../../references/integration.md)。把“小说质量”与“改编适配”分开评价；不因作品难以直接拍摄就否定其文学价值。

## 诊断

从已提供文本找出核心戏剧问题、主人公行动、人物关系、视觉空间和不可逆选择。标明作品最值得保留的东西，以及转媒介后最可能损失的叙述声音、心理层次或时间组织。

将内心变化转成可被观众理解的行为、选择、关系后果或视听线索。保留必要的叙述空间，不要求所有心理描写都换成旁白或解释性对白。

## 载体选择

电影：关注一个主要行动能否形成集中推进与结局。
剧集：关注矛盾能否持续产生不同的具体事件，每个单元如何推进整体关系或主线。
不掌握预计篇幅、素材量或目标形态时，给出条件性判断，不武断确定集数。

## 提案交付

按需求输出一句话提案、类型与受众假设、人物及关系、故事梗概、篇章或分集方向、独特场面和改编取舍。作者尚未批准的新情节标为建议，不冒充原作内容。

制作方面仅基于文本识别因素：场景转换、主要角色数量、年代还原、特殊拍摄条件与视效。没有预算与制作资料时不编造金额或可行性结论。

涉及真实人物、现实案件、版权链和当前市场时，明确所需核查材料；这份创作提案不替代权利审查或行业谈判。不得承诺签约、热播或版权价格。
