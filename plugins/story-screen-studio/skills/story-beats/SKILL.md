# 情节节奏

先读 [协作约定](../../references/integration.md)。本技能使用自行编写的诊断流程，不附带任何书籍动点表或原文。

## 读取与标记

先读大纲或相关章节，辨认开局状态、引发行动的变化、重大承诺、策略受挫、认知改变、最后选择与结果。它们是功能标签，不规定出现次数、名称或篇幅百分比；缺失标签未必是缺陷。

为每个重大转折标注：前因、谁作决定、付出代价、局势变化、对后续的约束。不能从材料证明的连接标为待补，不擅自编造。

## 三项检查

- 因果：事件之间是“因为所以”还是仅“接着发生”？偶然可制造困境，但反复替人物解决难题会削弱行动分量。
- 压力：新段落是否改变可选策略、关系或风险？重复升级危险却不改变选择，可能仍然停滞。
- 信息：读者知道、人物知道、作者知道分别是什么？反转应重释已给线索，不能依赖从未允许读者接触的关键事实来冒充公平推理。

## 修改方式

中段松散时，优先查目标是否过早完成、反对力量是否暂停行动、人物是否在重复旧策略。提出移位、合并、提前兑现或改变选择的方案，说明对前后文的影响。

不要把所有章节都改成同一长度、同一种钩子。安静段落可承担余波、关系重组和下一次选择的准备。

## 输出

交付“位置 / 当前作用 / 问题证据 / 建议变化 / 连锁影响”的精简列表，优先解决最影响主线的事项。若用户只请求设计，则提供可修改的节奏方案而非宣称唯一正确结构。
