# 故事审核

先读 [协作约定](../../references/integration.md)。审核不等于重写；除非用户要求，不直接修改正文。

## 四个视角

1. 读者体验：开篇承诺是什么，读者为何继续读，期待在哪里兑现或被有意义地改变？区别作者想表达与读者实际上获得的信息。
2. 结构因果：主要事件如何相互推动，关键结果是否来自选择，铺垫与后果是否可追溯？区分故意留白与因果断裂。
3. 人物表达：不同人物是否有不同利益、认知和表达策略？对白、行动、心理和叙述是否相互支持，而非重复解释？
4. 改编适配：哪些冲突可转为行动和关系，哪些魅力依赖文字声音？识别电影或剧集的承载空间、重复发生的矛盾与潜在制作难点，不预测成交率。

## 证据与优先级

每项意见包含位置、简短证据、判断、影响和可选修法。证据不足标记未知；个人偏好与逻辑矛盾分开。不要为凑齐四栏强行找问题。

先处理会影响故事成立的断裂，再处理情感兑现与节奏，最后处理局部表达。优先交付最重要的三项；较长稿件可附其他发现。

保留有效之处并说明应保护什么，避免修改建议互相冲突。若修复一个问题会损害作者风格，列出取舍，交由作者决定。不以机械总分替代论证。
