# 版本与发布边界

| 项目 | 本地完整版 | GitHub 精简版 |
| --- | --- | --- |
| 用途 | 个人创作资料与完整工作流留存 | 可独立安装的受限发布包 |
| 技能数量 | 30 | 8 |
| 用户原始资料与本地参考 | 保留于本地 | 不包含 |
| 未明确授权再分发的第三方材料 | 不向外发送 | 不包含 |
| Git 历史 | 原本地仓库保留 | 全新历史，不沿用完整版 |
| 安装 | 保留原安装 | 独立市场，按需安装 |

“精简版”表示发布范围经过收缩，并不表示已对所有潜在权利问题作出法律保证。第三方仅纳入明确标有 MIT 许可且已保留许可文本的三个组件；不能确认授权范围的材料不进入发布包。

新增内容为重新编写的通用创作协作指令，不随包携带私人附件或对原表格、书籍段落的逐项转录。后续贡献须说明来源、授权依据及修改情况；仅给出来源链接不等于获得转载许可。
