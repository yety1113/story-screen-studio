# GitHub 页面介绍

## 仓库名称

story-screen-studio

## About 简介

面向影视改编潜力的中文小说创作插件：故事设计、人物冲突、情节节奏、四视角审核与改编提案。GitHub 精简版含 8 个技能，保留第三方 MIT 声明。

## Topics

codex-plugin, agent-skills, creative-writing, chinese-fiction, storytelling, screenwriting, novel-writing

## 发布说明 · v0.1.0

首个独立 GitHub 精简版，包含 5 个重新编写的创作流程与 3 个 MIT 授权组件。覆盖灵感发展、故事设计、节奏审核、正文精修和影视提案。个人原始资料、书籍摘录、授权未明确的第三方内容及完整版提交历史均不包含在本包中。

## 一句话定位

先让小说成为好故事，再让它具备被改编的可能。
