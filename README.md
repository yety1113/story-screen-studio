# Story Screen Studio · 故事影视创作室

面向希望写出具有影视改编潜力的小说作者：从故事立意、人物选择、情节推进到改编提案，建立一套可反复使用的 AI 创作协作流程。

这不是“一键写爆款”，也不保证作品售出版权。它帮助你把模糊灵感变成可以讨论、写作、检验和修改的故事方案，同时保留小说自身的语言与阅读价值。

## 能做什么

- 把题材灵感整理为一句话故事、人物困境和长篇主线。
- 检查人物是否通过行动推动情节，而非被事件拖着走。
- 设计转折、场景和章节，检查铺垫、后果与信息分配。
- 从读者、结构、人物和改编四个角度提出有依据的修改建议。
- 将小说材料转成影视提案：可见行动、人物关系、分集引擎和制作风险。

## 本仓库版本

GitHub 精简版 v0.1.0，共 **8 个技能**：5 个重新编写的创作流程，3 个保留 MIT 许可证的第三方技能。无账号连接、无付费 API、无自动上传功能；使用时仍需运行它的 AI 工具。

本仓库不包含个人原始文档、书籍摘录库、未明确授予再分发许可的第三方技能，以及本地完整版的历史记录。完整版与本仓库独立保存。详见 [版本与发布边界](docs/EDITIONS.md) 和 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 技能一览

| 技能 | 用途 |
| --- | --- |
| story-studio | 统筹创作任务，选择下一步，维护已确认设定 |
| story-craft | 故事立意、人物困境、冲突与场景设计 |
| story-beats | 情节转折、节奏与因果检查 |
| story-audit | 四视角审核与修改优先级 |
| screen-adaptation | 小说改编诊断与影视提案 |
| novel-writing | 叙事因果、视角、对白及正文精修 |
| novel-writer-cn | 中文长篇设定、大纲和章节写作 |
| storyteller | 短篇、开场与情感叙事 |

## 安装与使用

将本仓库下载并解压，在支持插件的 Codex 中添加该目录作为本地插件市场，再安装 Story Screen Studio。命令方式见 [使用说明](docs/USAGE.md)。

第一次可以这样说：

> 使用 story-studio。我想写一部有影视改编潜力的悬疑长篇。先帮我判断核心故事能否成立，不要直接写正文。

已有稿件可以这样说：

> 使用 story-audit 审核这三章。引用具体位置区分事实与判断，给出最值得先改的三项，不要替我重写。

## 工作原则

作者拥有最后决定权。结构是诊断工具，不是硬套的公式；市场判断是待验证假设，不是销量或版权承诺。真实事件、人物隐私及素材使用权限需要单独核实。

本项目包含第三方 MIT 组件，但**不对整个仓库统一授予 MIT 许可**。新增文档和流程暂未另行授予开源许可；第三方授权范围按各自许可证执行。
